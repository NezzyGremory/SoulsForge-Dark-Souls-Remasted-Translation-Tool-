# ⚔️ SoulForge

### Dark Souls Remastered Translation Tool

**SoulForge** adalah proyek open-source yang sedang dikembangkan untuk membantu proses **pengelolaan, ekstraksi, dan penerjemahan teks** pada *Dark Souls Remastered*.

> 🚧 **Project Status: Early Development**
>
> SoulForge masih berada pada tahap awal pengembangan. Beberapa fitur utama masih dalam proses perancangan dan implementasi.

---

## 🎯 About

SoulForge dibuat dengan tujuan menyediakan workflow yang lebih mudah untuk komunitas modding dan translation.

Project ini nantinya akan berfokus pada:

* 📖 Pengelolaan teks game
* 🔎 Parser dan extractor file game
* 🌐 Translation workflow
* 📝 Editing teks
* 💾 Export dan import data
* 🛠️ Tools pendukung proses modding

Saat ini fokus utama project adalah membangun **fondasi dan sistem parser** sebelum fitur translation yang lebih kompleks dikembangkan.

## 🚀 Getting Started

### 1. Clone repository

```bash
git clone https://github.com/NezzyGremory/SoulsForge-Dark-Souls-Remasted-Translation-Tool-.git
cd SoulsForge-Dark-Souls-Remasted-Translation-Tool-
```

### 2. Create virtual environment

```bash
python -m venv venv
```

### 3. Activate virtual environment

**PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

Jika PowerShell memblokir script:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Kemudian:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install dependencies

Jika project sudah memiliki `requirements.txt`:

```bash
pip install -r requirements.txt
```
